# Party Time — лендинг

Ты верстаешь новый лендинг сети караоке-лофтов Party Time (Санкт-Петербург).

Перед любой работой прочитай:
1. `docs/TZ.md` — задача, стек, порядок шагов, приёмка
2. `docs/DESIGN_SYSTEM.md` — визуальные правила (главный источник по дизайну)
3. `content/content.md` и `content/rooms.json` — весь контент

Правила работы:
- Работай строго по шагам из `docs/TZ.md` §3. После шага 1 (два варианта hero и каталога залов) остановись и жди, пока заказчик выберет вариант.
- После каждого блока: `/impeccable critique`, затем правки, коммит и `git push` в `main`. Заказчик следит за процессом по репозиторию.
- Перед каждым пушем: `/impeccable polish` и проверка на AI-шаблонность.
- Коммиты на английском в формате conventional commits. Общение с заказчиком на русском.
- Не выдумывай факты (цены, часы, телефоны). Бери их только из `content/`. Если данных нет, оставь пометку `[уточнить]` и собери все такие пометки в список.
- Логотипы бери только из `brand/logo/`. Не перекрашивай их и не искажай. Контурных человечков из брендбука не используй.
- Шрифты: Unbounded (заголовки, 700–900) и Onest (текст).
