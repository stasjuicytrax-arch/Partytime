# Party Time — дизайн-система сайта

> Источник истины для вёрстки. Цвета и логотип взяты из брендбука (`PT Брендбук.pdf`, стр. 17–26). Шрифты сайта — Unbounded + Onest (решение заказчика, заменяют шрифты брендбука). Настроение и приёмы — из папки `Referens/`.
> Контурных человечков-маскотов из брендбука **не используем нигде**.

---

## 1. Идея и настроение

**«Вместе и громче».** Party Time — это не «антикафе с караоке», а 36 тематических миров, в которые компания заходит и становится звездой вечера. Сайт должен ощущаться как флаер с афиши лучшей вечеринки города: громкий, живой, слегка хулиганский, но собранный и удобный.

Три слова: **громко · тематично · по-своему**.

Что берём из референсов:

| Референс | Что забираем |
|---|---|
| `c9d95…` (golf le FLEUR) | Коллаж: вырезанные фото людей поверх цветных плашек, рукописные дудлы-стрелки и обводки маркером, сверхжирные заголовки, «бумажные» блоки разного цвета встык |
| `27.jpg` (Best Prom Night) | Розовый фон + лаймовый акцент, блёстки/диско-шар, наклейки-звёзды, кривые «таблетки»-лейблы под углом, бегущая строка на чёрном |
| `28.jpg` (Futura) | Тёмная сцена + 3D-объект с глянцем, нумерация секций `01 / 02`, карточки с иконкой-стрелкой в кружке, контраст «чёрный — лайм — розовый» |
| `e025a…` (Base Club) | Гигантская типографика на весь экран, стеклянные (glass) карточки поверх текста, круглая вращающаяся печать-стикер, стрелки-закорючки |
| `59228…` (Академия бровиста) | Мазки кистью под словами, контурные + залитые слова в одном заголовке, рваные края секций, отзывы бегущей строкой |
| `248dc…` (Pinterest glass) | Мягкий glassmorphism, большие скругления 32px+, сферы-градиенты — **только** для модалок и плавающих панелей, не для всего сайта |

Чего избегаем: шаблонный SaaS-лендинг (иконка + заголовок + 3 строки в сетке 3×N), «AI-градиенты» фиолет→синий на всю страницу, одинаковые скругления везде, стоковые 3D-люди.

## 2. Цвет

### 2.1 Палитра бренда (брендбук, стр. 24–25)

```css
:root {
  /* Primary — яркие */
  --pt-coral:   #FA3E35; /* Coral Red   — текст белый */
  --pt-pink:    #FE76B4; /* Hot Pink    — текст белый или тёмный */
  --pt-saffron: #FFC548; /* Saffron     — текст тёмный */
  --pt-green:   #00B487; /* Shamrock    — текст белый */
  --pt-sky:     #6CD0F0; /* Sky Blue    — текст тёмный */
  --pt-violet:  #7659FF; /* Slate Blue  — текст белый */

  /* Light (доп. палитра, подложки) */
  --pt-coral-l:   #FF7B75;
  --pt-pink-l:    #FF9FCB;
  --pt-saffron-l: #FFD478;
  --pt-green-l:   #56BEA4;
  --pt-sky-l:     #8BDEF9;
  --pt-violet-l:  #A693FF;

  /* Bright (доп. палитра, hover / active) */
  --pt-coral-b:   #F81E14;
  --pt-pink-b:    #FF5CA7;
  --pt-saffron-b: #FFB515;
  --pt-green-b:   #16886B;
  --pt-sky-b:     #2CBFEE;
  --pt-violet-b:  #5834FF;

  --pt-lime: #C9E543; /* Green Accent — главный «кислотный» акцент сайта */

  /* Нейтральные */
  --pt-white: #FFFFFF;
  --pt-dove:  #E8E8E8;
  --pt-ivory: #D2D2CA;
  --pt-fog:   #8A8A8A;
  --pt-storm: #282828; /* основной тёмный текст */
  --pt-deep:  #151515; /* фон тёмных секций */

  /* Служебные */
  --pt-paper: #F6F3EC; /* тёплая «бумага» для светлых секций (между white и ivory) */

```

> В брендбуке у части цветов RGB не совпадает с HEX — **всегда используем HEX**. У доп. палитры в PDF подписан один и тот же код — реальные значения сняты с образцов (выше).

### 2.2 Правила

- **Одна секция = один доминирующий цвет фона** + максимум 2 акцента. Многоцветие — только в стикерах, чипах и цветовой кодировке залов.
- Ритм фонов по странице: `deep → pink → paper → violet → paper → deep …` — соседние секции никогда не одного цвета.
- **Лайм `#C9E543`** — цвет действия: главные CTA, выделения маркером, активный фильтр. Не больше 10% площади экрана.
- Текст на цветном (брендбук, стр. 26): на Coral / Green / Violet — **белый**; на Pink / Sky / Saffron — **тёмный `#282828`** (белый допустим на Pink крупным кеглем).
- Логотип **не перекрашиваем**: всегда чёрные буквы на белой плашке с чёрной рамкой. Фон под логотипом — любой цвет палитры.
- Цветовое кодирование вместимости залов (используется в фильтрах и бейджах):
  `2–4` → sky · `6–8` → saffron · `8–10` → pink · `15–20` → violet.
- Локации: Думская → `--pt-pink`, Маяковская → `--pt-violet`; неактивные — `--pt-fog` на `--pt-dove`.

### 2.3 Контраст (WCAG AA)

`#282828` на всех primary — проходит. Белый на `#FFC548` / `#6CD0F0` / `#C9E543` — **запрещён** (не проходит). Белый на `#FE76B4` — только ≥ 24px bold.

## 3. Типографика

### 3.1 Шрифты

| Роль | Шрифт | Начертания | Где |
|---|---|---|---|
| Display | **Unbounded** (variable) | 700–900 | Заголовки секций, hero, названия залов на карточках, цены в таблетках и на круглых печатях, бегущая строка, цифры-счётчики |
| Text | **Onest** (variable) | 400–700 | Описания, интерфейс, кнопки, формы, FAQ, мелкий текст |
| Hand (опц.) | **Caveat** или **Marck Script** (кириллица) | 600–700 | Только рукописные подписи-дудлы рядом со стрелками («тут поют до утра →»). Максимум 1–2 на экран |

Подключение: `@fontsource-variable/unbounded`, `@fontsource-variable/onest` (self-host, `font-display: swap`, subset `cyrillic` + `latin`). Preload только Unbounded 800 для hero.

### 3.2 Шкала (fluid, clamp)

```css
--fs-mega:  clamp(3.5rem, 11vw, 11rem);   /* hero-слово, Unbounded 900, lh .86, ls -0.04em, UPPERCASE */
--fs-h1:    clamp(2.5rem, 6vw, 5.5rem);   /* Unbounded 900, lh .9,  ls -0.03em, UPPERCASE */
--fs-h2:    clamp(2rem, 4.2vw, 4rem);     /* Unbounded 800, lh .95, ls -0.02em, UPPERCASE */
--fs-h3:    clamp(1.25rem, 2vw, 1.75rem); /* Unbounded 700, lh 1.05 — названия залов */
--fs-lead:  clamp(1.125rem, 1.4vw, 1.375rem); /* Onest 500, lh 1.4 */
--fs-body:  1rem;      /* Onest 400, lh 1.55 */
--fs-small: .875rem;   /* Onest 500, lh 1.4 */
--fs-label: .75rem;    /* Onest 600, UPPERCASE, ls .08em — надзаголовки, «01 / ЗАЛЫ» */
```

### 3.3 Приёмы

- **Микс в одном заголовке**: залитое слово + контурное (`-webkit-text-stroke: 2px`) + слово на лаймовой плашке-маркере под наклоном −2°. Пример: `НАЙДИ` (залитый) `СВОЙ` (контур) `ЗАЛ` (на плашке).
- Заголовки — **всегда UPPERCASE Unbounded**, текст — никогда не капсом длиннее 4 слов.
- Длина строки текста — 45–65 знаков (`max-width: 38ch` для лидов).
- Неразрывные пробелы после предлогов и между числом и ₽ (`1 550&nbsp;₽`).
- Цифры в ценах: `font-variant-numeric: tabular-nums`.

## 4. Сетка и пространство

- Контейнер: `max-width: 1440px`, поля `clamp(16px, 4vw, 64px)`.
- Desktop: 12 колонок, gutter 24px. Tablet (≥768): 8 колонок. Mobile (<768): 4 колонки, gutter 16px.
- **Брейкпоинты**: 480 / 768 / 1024 / 1280 / 1600.
- Базовый шаг: 8px. Шкала отступов: `4 8 12 16 24 32 48 64 96 128 160`.
- Вертикальный ритм секций: `padding-block: clamp(72px, 10vw, 160px)`. Hero — `100svh` (min 640px).
- Композиция **асимметричная**: заголовок секции занимает 7–8 колонок слева, подзаголовок/лид — 3–4 колонки справа, выровнен по базовой линии заголовка (как в Futura).
- Нумерация секций: маленький label `01 — ЗАЛЫ` над заголовком (Onest 600, 12px, цвет fog/белый 60%).
- «Воздух»: на экране не больше одной крупной идеи. Между заголовком и контентом — 48–64px; между карточками — 16–24px.
- Объекты (стикеры, 3D, фото-вырезки) **выходят за границы** секций и контейнера, перекрывают стыки секций (z-index), создавая коллаж.

## 5. Форма и поверхности

| Токен | Значение | Применение |
|---|---|---|
| `--r-xs` | 8px | инпуты, мелкие чипы |
| `--r-md` | 20px | карточки залов |
| `--r-lg` | 32px | крупные панели, модалка |
| `--r-pill` | 999px | кнопки, таблетки цен, фильтры |
| `--border` | 2px solid `#151515` | «стикерная» обводка — фирменная черта (как рамка логотипа) |
| `--shadow-pop` | `6px 6px 0 #151515` | жёсткая тень у стикеров/CTA, при hover → `10px 10px 0` |
| `--shadow-soft` | `0 24px 60px -20px rgb(21 21 21 / .35)` | фото, модалки |
| `--glass` | `rgb(255 255 255 / .14)` + `backdrop-filter: blur(18px) saturate(1.4)` + 1px белая 30% рамка | только плавающие панели поверх фото/тёмного |

**Наклоны** — как плашки логотипа (3°, 1°, 2.5°): стикеры и лейблы поворачиваем на `-3° … +3°`. Не больше 3–4 наклонённых объектов на экран.

**Рваный край / волна** между некоторыми секциями — SVG-маска (как в «Академии бровиста»), не чаще чем через 2 секции.

## 6. Компоненты

### Кнопки
- **Primary**: лайм `#C9E543`, текст `#151515`, Onest 700 16px, высота 56px, pill, `--border` + `--shadow-pop`. Справа — чёрный круг 40px со стрелкой ↗. Hover: тень растёт, стрелка поворачивается на 45°, лёгкий `translate(-2px,-2px)`.
- **Secondary**: прозрачная, белая/чёрная рамка 2px, pill. Hover: заливка.
- **Ghost-link**: текст + подчёркивание-мазок SVG, рисуется при hover.
- Min touch-target 48×48.

### Таблетки цен и печати
- **Price pill**: Unbounded 800, `от 1 550 ₽/час`, фон белый, рамка 2px, наклон −2°.
- **Round stamp** (круглая печать 120–160px): текст по окружности Unbounded 700 UPPERCASE («БРОНИРУЙ • ПОЙ • ТАНЦУЙ •»), в центре цифра/иконка. Медленно вращается (20s linear infinite), на hover — ускоряется. Используется: hero, карточки топ-залов, CTA.

### Чипы / фильтры
Pill 40px, Onest 600 14px, рамка 2px. Активный — заливка цветом вместимости (см. 2.2). Счётчик в чипе: `6–8 гостей · 11`.

### Карточка зала (ключевой компонент)
- Соотношение фото 4:5, `--r-md`, обводка 2px.
- Фото — слайдер (на desktop листается **движением курсора по карточке**, точки-индикаторы сверху как в stories; на mobile — свайп).
- Поверх фото снизу: название зала Unbounded 700 22px (белое с тенью или на цветной плашке), tagline Onest 14px.
- Бейджи сверху: вместимость (цвет группы) · площадь м².
- Справа сверху — **price pill под наклоном**.
- Hover: карточка приподнимается, наклоняется на 1° (tilt по курсору ≤ 4°), тень `--shadow-pop` цвета группы, появляется кнопка «Смотреть зал».
- Клик → модалка зала (галерея, описание, «Что входит», CTA «Забронировать этот зал»).

### Бегущая строка (marquee)
Unbounded 800, 48–96px, UPPERCASE, разделители — звёзды-стикеры ✦ или мини-логотип «P». Две строки в противоположные стороны, наклон ленты −2°. Скорость реагирует на скролл (ускоряется при прокрутке).

### Стикеры и дудлы
- SVG-стикеры: звезда-искра (лайм), молния, сердце, микрофон, нота, «18+ до 6 утра», «NEW» — плоские, с обводкой 2px и `--shadow-pop`.
- Рукописные дудлы (стрелки, обводки, закорючки) — SVG-path с анимацией `stroke-dashoffset` при появлении. Толщина 3–4px, цвет лайм/чёрный/белый.
- 3D-иконки (3dicons, CC0): микрофон, нота, звезда, огонь, подарок, корона, сердце, наушники, пин. Используем как «парящие» объекты с параллаксом, максимум 2–3 на экран.

### Формы
Инпуты 56px, `--r-xs`, фон белый, рамка 2px `#151515`, фокус — лаймовая тень 4px. Пошаговые формы — один вопрос на экран, прогресс-бар-«эквалайзер».

## 7. Движение (анимации)

Стек: **GSAP + ScrollTrigger** (анимации и пины), **Lenis** (плавный скролл), **SplitType** (разбиение текста), опционально **Three.js** (3D диско-шар в hero, вариант B).

| Приём | Где | Параметры |
|---|---|---|
| Прелоадер-«микрофонная проверка» | первый заход | ≤ 1.2s: «РАЗ, РАЗ… ПРОВЕРКА» → логотип «впрыгивает» с overshoot → шторка уезжает вверх |
| Kinetic headline | hero, H2 | строки выезжают снизу из маски по словам, `stagger .06`, `ease: expo.out`, 0.9s |
| Коллаж-сборка | hero | фото-вырезки и стикеры прилетают с поворотом и «шлёпаются» (`back.out(1.7)`), затем мягко парят (`yoyo`, 3–5s) |
| Магнитные кнопки | все CTA | смещение к курсору ≤ 8px |
| Курсор-микрофон | desktop | кастомный курсор-кружок; над карточкой зала превращается в «СМОТРЕТЬ», над CTA — в 🎤 |
| Параллакс слоёв | стикеры, 3D | скорость 0.8–1.3 от скролла |
| Горизонтальный скролл-пин | «Форматы праздника» | секция пинится, карточки едут влево |
| Счётчики | цифры (36 залов, до 06:00) | count-up при входе в экран |
| Рисование дудлов | стрелки, обводки | `stroke-dashoffset` 0.8s при входе |
| Смена фона секции | переходы | фон body плавно перетекает в цвет следующей секции на ScrollTrigger |
| Marquee от скролла | бегущие строки | скорость ×(1 + velocity) |

Правила: длительности 0.4–0.9s, только `transform`/`opacity`/`clip-path`; 60fps на среднем Android; **всё отключается/упрощается при `prefers-reduced-motion: reduce`**; ничего не мигает чаще 3 раз в секунду.

## 8. Фото и графика

- Основа визуала — **реальные фото залов** (36 залов, `public/img/rooms/`) и фото гостей из `Photo/` (фотограф Роман Бастриков).
- Фото гостей (девушки с микрофонами, с коктейлем, с «Оскаром», с геймпадами) — вырезаем фон (PNG с прозрачностью) и используем в коллажах как в референсе golf: вырезка + цветная плашка + дудл.
- Обработка: лёгкий тёплый грейдинг, контраст +10, без фильтров «под плёнку». Опционально — дуотон (deep + цвет секции) для фоновых фото.
- Зерно (noise) 3–4% поверх цветных секций — SVG-filter, придаёт «печатность».
- Иконки интерфейса — Phosphor Icons (bold) или Lucide, 24px, stroke 2.

## 9. Голос и тон

На «вы», дружелюбно, коротко, с юмором и отсылками к залам. Глаголы действия: «Пой», «Бронируй», «Выбирай», «Собирай своих». Без канцелярита («осуществляется бронирование» → «Бронируем за 2 минуты»). Заголовки — 2–4 слова.

Примеры: «ВМЕСТЕ И ГРОМЧЕ» · «36 МИРОВ ДЛЯ ВАШЕЙ КОМПАНИИ» · «ТОЛЬКО СВОИ. ВЕСЬ ЗАЛ — ВАШ» · «ПОЁМ ДО 06:00» · «ПРИНОСИТЕ СВОЁ. ПРОБКОВОГО СБОРА НЕТ».

## 10. Доступность и качество

- Контраст AA, видимый focus-ring (лайм 3px + offset 3px).
- Все интерактивы доступны с клавиатуры, модалки с focus-trap и `Esc`.
- `alt` у всех фото залов: «Зал „Диско“ на Думской: зеркальный шар и диванная зона».
- Изображения: AVIF/WebP, `srcset`, lazy, явные `width/height`. LCP < 2.5s, CLS < 0.05.
- Семантика под будущее SEO: один `<h1>`, иерархия h2/h3, `<section aria-labelledby>`, JSON-LD `LocalBusiness` на каждую локацию (заполним позже, но разметка-заготовка обязательна).
